# FFPS_Salvage2020

Repo for my **recreation** of the salvage minigame in *Freddy Fasbear's Pizzaria Simulator*.

Initially built in Unity 6.1 (now downgraded to Unity 2020 LTS) from 18/04/2025 to 21/04/2025, this Unity build tries to recreate the experience of the salvage.

Textures & Sounds were directly ripped from the official game.  
Game Mechanics based off [ItzTaken's explanation on YouTube](https://youtu.be/6fByPNcI6LA?t=615).
